# Open coverage gaps

This register lists behavior that is absent, contradicted, or not yet proven. It
is a factual companion to the [roadmap](roadmap.md), not a second backlog.

## How gaps are ranked

- **Critical** can permit unintended local execution, corrupt shared state, leak
  credentials, or make the primary verification gate unreliable.
- **High** can invalidate a milestone, misrepresent supported behavior, or break
  recovery and interoperability.
- **Medium** leaves an important path without direct evidence but has a bounded
  current blast radius.

A gap closes only when its closure evidence exists and passes. Documentation or
configuration alone does not close a behavioral gap.
